# TouchlessPC – Voice & Gesture Control Assistant

A contactless Windows PC assistant that combines voice commands and hand gestures for hands-free computer control.

## Features

- Voice commands
- Hand gesture recognition
- Volume control
- Mute / Unmute
- Play / Pause
- Next / Previous track
- Screenshot capture
- Application launching
- Contactless interaction

## Technologies

- Python
- OpenCV
- MediaPipe
- SpeechRecognition
- PyCaw
- PyAudio
- PyAutoGUI
- Pyttsx3
